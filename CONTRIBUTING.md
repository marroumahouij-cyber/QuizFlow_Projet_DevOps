## Règles de collaboration
1. Utiliser la branche dev pour intégrer les modifications.
2. Créer une branche feature/nom pour une nouvelle contribution.
3. Enregistrer les modifications avec un commit clair.
4. Ouvrir une Pull Request vers dev.
5. Vérifier les tests avant de fusionner la Pull Request.

## Objectif DevOps
Collaborer sur une application de Quiz interactif et automatiser son intégration avec GitHub, Jenkins et Docker.
